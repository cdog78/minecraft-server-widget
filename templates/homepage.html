MINECRAFT SERVER WIDGET


This project allows minecraft server owners to advertise their server in a flashy, cool way!

FEATURES

  • Shows server icon, motd and url in one simple package

  • Players can click the widget to copy your server IP and start playing with a click!

  • User freindly iframe generator to allow easy access to this service

ABOUT

This widget was built in python and uses the flask library for a web server and the mcstatus library to ping minecraft servers. Thanks to the developers of these awesome libraries! The font used is Micro 5 from Google Fonts.
