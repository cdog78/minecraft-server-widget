**FEATURES**

Shows server icon, motd and url in one simple package


Players can click the widget to copy your server IP and start playing with a click!


User friendly iframe generator to allow easy access to this service



**ABOUT**

This widget was built in python and uses the [flask library](https://pypi.org/project/Flask/) for a web server and the [mcstatus library](https://pypi.org/project/mcstatus/) to ping minecraft servers. Thanks to the developers of these awesome libraries! The font used is [Micro 5](https://fonts.google.com/specimen/Micro+5?query=micro&preview.script=Latn) from Google Fonts.
